## ✨ Features
- **Comprehensive Healthcare Departments**: Cardiology, Neurology, Orthopedics, Oncology, Pediatrics, and more.
- **Doctor Directory & Profiles**: Detailed specialist credentials, consultation fees, experience, and schedules.
- **Online Appointment Booking**: Multi-step booking system with real-time slot selection and instant verification.
- **Secure Patient Portal**: Google and Email/Password authentication powered by Firebase.
- **Administrative Command Center**: Secure hospital administrator portal for appointment scheduling, status tracking, and operations management.
- **Responsive & Modern UI**: Built with React 19, Tailwind CSS v4, Lucide icons, and Motion animations.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or bun

### Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/saaketh7619/wecare-hospitals.git
   cd wecare-hospitals
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
